Practical Data

Shades the comparable columns of web tables. A decision model judges which columns are amounts, which direction is better, which labels are ranked, and whether to compare by rows or columns.

Decision model

Keys stay in this browser's extension storage and are only sent to the provider you pick.

Palette

Each palette has a light and a dark version, picked automatically from the page's background.

Preview uses example judgments. Press Test to have the model judge this table.

Where to shade

    Use the toolbar button to turn a page or a site on or off. ⌥⇧H toggles the current page.

    What leaves your browser

    To judge a table, the extension sends the page title, the table's caption and headers, a few sample values from each column, the distinct labels in label columns, and the first and last two rows to the provider you picked above. Nothing is sent for tables you never scroll near, for sites you turn off, or for pages that opt out. Answers are cached in this browser, so an unchanged table is not sent twice. Your API key stays in this browser's extension storage. It is read by the extension's own pages (this one, the popup) and its background worker, and sent only to the provider you picked; web pages and the scripts that run on them can't read it.
