Column names below a blank header

A basketball box score can put the player names in one table and the numbers in a second table beside it. The numbers table has a header row with no text, to line up with the names table, and writes its column names (MIN, PTS, FG, 3PT and so on) in the first body row. That row is the header, even though "3PT" starts with a digit. The bench section repeats the column names in a body row of its own.
