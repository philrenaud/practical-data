Scores with qualifiers

A model maker's score table: tests as rows, models as columns. A score can carry a qualifier under it in its own element ("High effort", "with tools"), which reads as text after the percentage. For narrow screens the table repeats each test's label in a row of its own above the scores, hidden with aria-hidden. Those rows must not read as blank data rows, and the first must not join the header. The table compares across rows.
